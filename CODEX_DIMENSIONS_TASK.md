# Задача Codex: применить размеры из прайса к /next/

Источник размеров уже добавлен в репозиторий:

`data/forma-home-dimensions-from-price.tsv`

В файле только товары, которые есть в текущем реестре сайта. Поля:
- `modelId`
- `sourceIds`
- `dimensions`

## Что сделать

1. Прочитать `data/forma-home-dimensions-from-price.tsv` полностью.
2. Сопоставлять товары прежде всего по `modelId` и указанным `sourceIds`.
3. Добавить найденные размеры к соответствующим товарам сайта `/next/` так, чтобы существующий блок «Размеры» показывал их.
4. Использовать этот файл как дополнительный источник только там, где у конкретного товара/варианта размеры сейчас отсутствуют.
5. Не затирать более подробные существующие variant-specific размеры.
6. Если у строки несколько размеров через `|`, сохранить все значения; не выбирать одно произвольно.
7. Ничего не угадывать и не переносить размеры между похожими моделями.
8. Не менять цены, фото, цвета, группировку, registry/manualEvidence, root site и дизайн.
9. Не добавлять товары, которых нет на сайте.

## Проверка

После изменений:
- посчитать, сколько моделей/вариантов получили размеры из TSV;
- убедиться, что ни один sourceId не потерян и не задублирован;
- проверить `node --check` изменённых JS;
- запустить существующий registry audit;
- отдельно проверить, что размеры отображаются в modal `/next/` для нескольких товаров, которые раньше были без размеров.

Сделать отдельный commit. Если среда позволяет — создать PR в `codex-current`. В финальном отчёте перечислить изменённые файлы, количество добавленных размеров, тесты, commit SHA и PR.
