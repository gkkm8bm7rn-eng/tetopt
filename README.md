# FORMA HOME

**AI-assisted e-commerce catalog · product logic · data validation · QA**

FORMA HOME — рабочий каталог мебели и предметов интерьера, созданный из большой товарной Excel-базы без отдельного бюджета на разработку. Проект показывает путь от исходных данных поставщика до публичного web-инструмента, в котором пользователь может найти товар, выбрать конкретное исполнение, сохранить его и подготовить заказ менеджеру.

## О проекте

Изначальная задача была практической: сделать удобный электронный каталог для оптовых клиентов на основе существующего товарного прайса.

По мере работы каталог вырос в полноценный web-инструмент с поиском, категориями, вариантами товаров, избранным, корзиной и подготовкой обращения менеджеру. Приоритетом была не максимальная функциональность сама по себе, а точность товарных данных и понятный путь пользователя от поиска до заявки.

## Ключевые технические решения

### Точная идентификация товара

Карточки опираются на реальные `sourceId`. Похожие названия сами по себе не считаются основанием для объединения товаров. Это снижает риск появления несуществующих сочетаний цены, цвета, размера или фотографии.

Текущий публикационный каталог сохраняет все 1 196 покупаемых вариантов; `sourceId` остаются уникальными.

### Подготовка данных отдельно от интерфейса

Покупательская группировка формируется из проверенных данных заранее. Одна конструктивная модель отображается как одна карточка, а подтверждённые исполнения остаются вариантами внутри неё. У каждого варианта сохраняются собственные цена, характеристики, фотографии и идентификатор корзины.

### Разделение данных для более быстрой загрузки

Главный каталог использует компактный `data/catalog-index.json`. Полные характеристики и галереи разделены на небольшие блоки в `data/details/` и загружаются при открытии конкретной карточки.

### Сохранение контекста пользователя

Категория, поисковый запрос, сортировка, номер страницы и позиция прокрутки сохраняются в истории браузера. При возврате назад пользователь попадает в прежнее место каталога, а не начинает поиск заново.

### Устойчивость к отдельным сбоям загрузки

Для detail-данных предусмотрен резервный запрос к `raw.githubusercontent.com` той же ветки `main`, чтобы единичная ошибка загрузки не останавливала весь каталог.

### Аналитика без собственных просмотров

Cloudflare Web Analytics подключается для обычных посетителей. Для браузеров команды предусмотрен внутренний режим, при котором аналитический маяк не загружается.

## AI-assisted development

AI использовался как рабочий инструмент разработки, анализа и ускорения итераций.

Моя задача состояла не в том, чтобы принять сгенерированный результат как готовый, а в том, чтобы формулировать требования, разбивать работу на проверяемые этапы, сопоставлять решения с реальными товарными данными, находить несоответствия и доводить систему до рабочего состояния.

Продуктовая логика, критерии качества и финальная проверка оставались отдельной частью работы.

## QA и проверка данных

В проекте отдельно проверялись:

- корректность вариантов одной модели;
- дубликаты и ошибочные объединения товаров;
- соответствие цены, характеристик и фотографий выбранному варианту;
- уникальность идентификаторов и сохранность покупаемых вариантов;
- работа поиска, категорий и пагинации;
- сохранение избранного и корзины;
- возврат пользователя к прежнему состоянию каталога;
- формирование заказа и передача выбранных позиций менеджеру;
- основные сценарии на мобильных устройствах.

## Локальный запуск

Для просмотра проекта локально достаточно обычного HTTP-сервера:

```bash
python3 -m http.server 8080
```

После запуска откройте `http://localhost:8080`.
