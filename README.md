# FORMA HOME — GitHub Pages

Готовый статический сайт.

## Публикация

1. Откройте репозиторий `gkkm8bm7rn-eng/tetopt` на GitHub.
2. Нажмите **Add file → Upload files**.
3. Распакуйте ZIP на компьютере и перетащите в окно GitHub файлы:
   - `index.html`
   - `.nojekyll`
   - `README.md`
4. Внизу страницы нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
7. Нажмите **Save**.

Ожидаемый адрес сайта:
`https://gkkm8bm7rn-eng.github.io/tetopt/`

## Важно об изображениях

Интерфейс не показывает кнопки или ссылки на поставщика и фотобанк. Фотографии выводятся внутри карточек товара.

Текущая версия определяет адреса фотографий через внешние страницы и публичные CORS-прокси. Поэтому сам сайт будет опубликован на GitHub Pages, но доступность отдельных фотографий зависит от внешних сервисов и сайта поставщика.

Для полностью стабильной коммерческой версии фотографии нужно заранее скачать в собственное хранилище/CDN и заменить внешние адреса на адреса вашего домена.
