# FORMA Atelier Zero

Новый лёгкий каталог, написанный с нуля без переноса старой архитектуры.

## Источник данных

В ветке зафиксирована проверенная копия `catalog.json` из `main`. В ней уже закреплены решения по объединению моделей: сайт не объединяет товары по похожим названиям и не создаёт несуществующие сочетания вариантов. Карточка опирается на точные `sourceId`, цены, характеристики и фотографии каждого варианта.

## Архитектура

- чистые HTML, CSS и JavaScript без фреймворка и сборщика;
- 24 модели на странице;
- поиск, категории, цена, фильтр вариантов, сортировка и пагинация;
- выбор реального варианта товара с его ценой, фото и характеристиками;
- избранное, просмотренные товары и корзина хранятся локально;
- адаптивная вёрстка и клавиатурная навигация;
- товарные данные зафиксированы в этой ветке, а фотографии читаются из общего проверенного хранилища репозитория, без дублирования тысяч файлов.

Для локального запуска нужен HTTP-сервер, например `python3 -m http.server 8080`.
