# FORMA HOME

Рабочий e-commerce каталог, созданный из товарной Excel-базы без отдельного бюджета на разработку. Поиск, категории, варианты товаров, избранное, корзина и подготовка обращения менеджеру собраны в одном рабочем web-инструменте.

**[Открыть работающий проект](https://gkkm8bm7rn-eng.github.io/tetopt/)**

Рабочая версия каталога. Основная и единственная рабочая ветка для сайта — `main`.

## Источник данных

В `main` зафиксирована проверенная копия `catalog.json`. В ней уже закреплены решения по объединению моделей: сайт не объединяет товары по похожим названиям и не создаёт несуществующие сочетания вариантов. Карточка опирается на точные `sourceId`, цены, характеристики и фотографии каждого варианта.

## Архитектура

- чистые HTML, CSS и JavaScript без фреймворка и сборщика;
- 24 модели на странице;
- компактный поиск, четыре основные категории и прямой выбор подкатегорий без выпадающих меню;
- категории назначаются по реестру `data/category-assignments.json`, собранному из утверждённого Excel-файла; один товар может состоять сразу в нескольких категориях;
- цена, фильтр вариантов, сортировка и пагинация;
- выбор реального варианта товара с его ценой, фото и характеристиками;
- избранное, просмотренные товары и корзина хранятся локально;
- адаптивная вёрстка и клавиатурная навигация;
- товарные данные и фотографии читаются из проверенного состояния ветки `main`; рабочий код не зависит от прежних веток проекта.

## Витрина и скорость

- `merchandising.json` хранит редактируемые правила и утверждённые приоритетные артикулы;
- главный каталог читает компактный `data/catalog-index.json`, уже собранный в маркетинговом порядке;
- полные галереи и характеристики разделены на небольшие блоки `data/details/` и загружаются только при открытии карточки;
- состояние каталога (категория, поиск, сортировка, номер страницы и прокрутка) сохраняется в истории браузера, поэтому кнопка «Назад» возвращает покупателя к тому же месту;
- при сбое загрузки отдельного detail-shard резервный запрос идёт в `raw.githubusercontent.com` той же ветки `main`;
- ссылки могут восстановить отдельный вариант, избранное или корзину;
- из корзины формируется готовое обращение для WhatsApp, Telegram и электронной почты `postes@mail.ru`;
- общая ссылка восстанавливает выбранные товары и количества и автоматически открывает корзину;
- в заказ включено уведомление, что окончательное наличие и срок отгрузки подтверждает менеджер.

Для локального запуска нужен HTTP-сервер, например `python3 -m http.server 8080`.

## Аналитика без внутренних просмотров

Cloudflare Web Analytics загружается для обычных посетителей и автоматически учитывает переходы внутри каталога. Браузеры команды можно один раз пометить как внутренние; на них аналитический маяк после этого вообще не загружается.

- GitHub Pages: [включить внутренний режим](https://gkkm8bm7rn-eng.github.io/tetopt/?tetopt_internal=on)
- Worker-зеркало: [включить внутренний режим](https://tetopt.m78m6cfc2v.workers.dev/?tetopt_internal=on)
- GitHub Pages: [вернуть обычный учёт](https://gkkm8bm7rn-eng.github.io/tetopt/?tetopt_internal=off)
- Worker-зеркало: [вернуть обычный учёт](https://tetopt.m78m6cfc2v.workers.dev/?tetopt_internal=off)

Служебный параметр удаляется из адресной строки автоматически. Метка хранится только в текущем браузере и только для выбранного домена, поэтому внутренний режим нужно включить отдельно на каждом устройстве, в каждом профиле браузера и на обоих адресах, которыми пользуется команда. Ссылки включения не следует пересылать покупателям.
