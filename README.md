# FORMA HOME

Рабочий e-commerce каталог мебели и предметов интерьера, созданный из товарной Excel-базы без отдельного бюджета на разработку.

**Live demo:** https://gkkm8bm7rn-eng.github.io/tetopt/

## О проекте

Задача проекта — превратить большой товарный каталог в понятный web-инструмент, которым можно пользоваться не только как электронной витриной, но и как частью реального процесса продаж.

В результате появился адаптивный каталог с поиском, категориями, вариантами товаров, избранным, корзиной и подготовкой обращения менеджеру. Отдельное внимание было уделено точности товарных данных, корректной работе вариантов и удобству навигации по большому ассортименту.

## Что реализовано

- поиск по каталогу;
- основные категории и подкатегории;
- фильтрация, сортировка и пагинация;
- выбор реального варианта товара с его ценой, фотографиями и характеристиками;

- сохранение состояния каталога при переходах назад и вперёд в браузере;
- адаптивная вёрстка и клавиатурная навигация;
- Cloudflare Web Analytics с возможностью исключать внутренние просмотры команды.

## Ключевые технические решения

### Точная идентификация товара

Карточки опираются на реальные `sourceId`. Похожие названия сами по себе не считаются основанием для объединения товаров. Это снижает риск появления несуществующих сочетаний цены, цвета, размера или фотографии.

### Разделение данных для более быстрой загрузки

Главный каталог использует компактный `data/catalog-index.json`. Полные характеристики и галереи разделены на небольшие блоки в `data/details/` и загружаются только при открытии конкретной карточки.

### Сохранение контекста пользователя

Категория, поисковый запрос, сортировка, номер страницы и позиция прокрутки сохраняются в истории браузера. При возврате назад пользователь попадает в то же место каталога, а не начинает поиск заново.

### Устойчивость к отдельным сбоям загрузки

Для detail-данных предусмотрен резервный запрос к `raw.githubusercontent.com` той же ветки `main`, чтобы единичная ошибка загрузки не ломала работу всего каталога.

### Аналитика без собственных просмотров

Cloudflare Web Analytics подключается для обычных посетителей. Для браузеров команды предусмотрен отдельный внутренний режим, при котором аналитический маяк не загружается.

## AI-assisted development

Проект создавался с использованием AI как рабочего инструмента разработки.

Моя задача состояла не в том, чтобы принять сгенерированный результат как готовый, а в том, чтобы формулировать требования, разбивать работу на проверяемые этапы, сопоставлять решения с реальными товарными данными, находить несоответствия и доводить систему до рабочего состояния.

AI использовался для ускорения разработки, анализа и итераций. Проверка данных, продуктовая логика, критерии качества и финальные решения оставались отдельной частью работы.

## QA и проверка данных

В проекте отдельно проверялись:

- корректность вариантов одной модели;
- дубликаты и ошибочные объединения товаров;
- соответствие цены, характеристик и фотографий выбранному варианту;
- работа поиска и категорий;
- сохранение избранного и корзины;
- возврат пользователя к прежнему состоянию каталога;
- формирование заказа и передачу выбранных позиций менеджеру;
- основные сценарии на мобильных устройствах.
